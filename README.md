# 買い増しタイミング判定(kabu-buy-timing)

日経平均・オルカン(ACWI)・金(ゴールド)を積み立てている人向けに、**調整局面での買い増しタイミング**を
恐怖指標×価格指標のスコアで判定する GitHub Pages ダッシュボードです。

- 公開ページ: `https://<ユーザー名>.github.io/kabu-buy-timing/`
- データは GitHub Actions が 1日2回(7:35 JST / 16:10 JST)自動取得して更新します
- 対象:日経平均(^N225)/ オルカン(ACWI ETF)/ 金(GLD ETF)

## 使っている指標(0〜100点で合算)

### 市場全体の恐怖(50点)— 日本と米国で使う指標を分けている

**日経平均:**
| 指標 | 配点 | 出典 |
|---|---|---|
| 日経平均VI(日経恐怖指数) | 20点 | 日経公式CSV(不可時はVIXで代替) |
| 騰落レシオ(25日) | 30点 | 日経225構成銘柄の日次騰落から自前計算(Yahoo Finance)。不可時はスクレイプ→F&G+プットコールの順で代替 |

**オルカン(ACWI):**
| 指標 | 配点 | 出典 |
|---|---|---|
| VIX(恐怖指数) | 20点 | Yahoo Finance `^VIX` |
| Fear & Greed 指数 | 15点 | CNN Business |
| プットコールレシオ | 15点 | CNN Fear & Greed の構成データ |

日経VIは平常時の水準がVIXよりやや高いため、閾値も少し上(22/27/32/42)に設定。
騰落レシオは 70%以下=売られすぎ、60%未満=歴史的底値圏 という一般的な目安に
沿って配点しています(85以上:0点 / 75-85:8点 / 70-75:15点 / 60-70:24点 / 60未満:30点)。

### 資産ごとの押し目の深さ(50点)— 日経平均 / ACWI それぞれで計算
| 指標 | 配点 | 内容 |
|---|---|---|
| 52週高値からの下落率 | 20点 | どれだけ調整したか |
| RSI(14日) | 15点 | 売られすぎの度合い |
| 200日移動平均線との乖離 | 15点 | 長期トレンドからの下振れ |

オルカンの価格指標は実際の購入通貨に合わせて**円建て換算値(ACWI×ドル円)**で
計算します。株安+円高で円建てが深く下がるほどスコアが上がり、円安が
クッションになっている間(例: 2022年)は上がりにくくなります。
為替が取得できない場合はドル建てで自動代替します。

### 金(ゴールド/GLD)— 価格指標のみで100点
金は恐怖局面で逃避先として買われ、株式と逆に動きやすいため、VIX等の恐怖指標は
スコアに使いません(下落率40点+RSI 30点+200日線乖離30点)。

⚠️ 金には利益や配当のような「割安さのアンカー」がないため、下落率=割安とは
限りません。構造上、金は株式よりレベル4(絶好のチャンス)が出やすい配点に
なっている点に注意してください。

### 判定レベル
| スコア | 判定 |
|---|---|
| 0–19 | ⏸️ 通常の積立のみ |
| 20–39 | 👀 調整の兆し・注視(資金準備) |
| 40–64 | 🛒 買い増し検討(資金の一部を投入) |
| 65–100 | 🔥 絶好の買い増しチャンス(分割しつつ積極投入) |

ドル円は円建てオルカンへの影響が大きいため**参考表示**しています(スコア対象外)。

## セットアップ(初回のみ・1ステップ)

リポジトリの **[Settings → Pages](../../settings/pages)** で以下を設定して Save:

- **Build and deployment → Source**: `Deploy from a branch`
- **Branch**: `gh-pages` / `(root)`

1〜2分後に `https://<ユーザー名>.github.io/kabu-buy-timing/` で公開されます。
以後はワークフローが `gh-pages` ブランチを自動更新するため、追加の操作は不要です。

## 構成

```
index.html              ダッシュボード本体
assets/style.css        スタイル(ライト/ダーク対応)
assets/app.js           描画ロジック(依存ライブラリなし)
data/data.json          市場データ+判定結果(Actions が自動更新)
scripts/fetch_data.py   データ取得・指標計算・スコアリング(Python 標準ライブラリのみ)
.github/workflows/update-data.yml  定期実行+Pages デプロイ
```

ローカル確認:

```bash
python3 scripts/fetch_data.py            # 実データ取得(ネット接続が必要)
python3 scripts/fetch_data.py --sample   # ダミーデータ生成
python3 -m http.server 8000              # → http://localhost:8000
```
